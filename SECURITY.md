# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for the Byakugan Core repository instead:

1. Open the repository's **Security** tab.
2. Choose **Advisories**, then **Report a vulnerability**.
3. Include affected versions, impact, reproduction steps, and any proposed
   mitigation. Do not include real credentials, customer data, or payment data.

The maintainers will acknowledge the report through the private advisory,
coordinate remediation, and publish disclosure information when a fix is
available. If private vulnerability reporting is unavailable, contact the
repository owner privately through their GitHub profile rather than publishing
exploit details.

## Supported versions

Security fixes are provided for the latest released version. Users should
upgrade to the latest patch before reporting an issue already resolved there.
